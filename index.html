Before you hand it over交给它之前

If it compiles, will the ad show?编译过了，广告就会出现吗？
No. A green build only means the SDK linked. A real test ad on a phone is a different check. Live ads still need your own AdMob account. 不会。编译通过只说明 SDK 已经链进去了。手机上能不能播出测试广告，是另一项检查。正式广告还是要用你自己的 AdMob 账号。
What if I do not have the Android SDK?我还没装 Android SDK 怎么办？
The Android build is skipped, and the report says so. If iOS built, that layer can still pass. Android is not pretended to be done. Android 构建会被跳过，报告里会写清楚。如果 iOS 编过了，这一层仍可通过。它不会假装 Android 已经验证完。
Will it wreck the app my agent already wrote?会不会把 Agent 已经写好的应用改坏？
No. New files go under lib/ads. Existing settings are left alone. The few lines in main.dart sit between markers. If a file it needs still has uncommitted edits, it waits for you. 不会。新文件只放在 lib/ads。已有配置原样保留。main.dart 里那几行改动夹在标记中间。它要改的文件如果还有未提交的修改，会先停下来等你。
Why did rewarded video fail on Android in mainland China?为什么激励视频在中国大陆的 Android 上播不出来？
Google served the test video from a CDN the Android ad view could not load. The same code played on iOS, and on Android through a proxy. The integration was fine. The network was not. Google 把测试视频放到了 Android 广告视图加载不了的 CDN 上。同一套代码在 iOS 能播，Android 走代理也能播。接入没问题，是网络过不去。
Can it log into AdMob for me?能替我登录 AdMob 吗？
No. You create the app, the ad units, and the privacy messages in AdMob. The tool never takes your password. 不能。应用、广告位和隐私消息都要你自己在 AdMob 后台建。它不会拿你的密码。
What about AppLovin MAX and LevelPlay?AppLovin MAX 和 LevelPlay 呢？
You can compare them here. They are not written into the project yet. A Unity game using LevelPlay is sent to Unity’s own skill. 你可以在这里比较它们，但还不会写进工程。Unity 游戏要用 LevelPlay，会转给 Unity 自己的 Skill。
How do I swap the test ads for real ones?测试广告怎么换成正式的？
Pass your live IDs at build time with --dart-define. You do not edit the source. If a test ID is still in the release, the check fails before you ship. 打包时用 --dart-define 传入正式 ID，不用改源码。正式包里如果还留着测试 ID，检查会在上线前拦住你。
